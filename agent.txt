4. Quick Start Guide (From Zero)
Step 1: Install Production Dependencies
Bash
pip install -r requirements.txt
(Optional: On your offline training PC, install PyTorch via pip install -r requirements-train.txt).
Step 2: Train & Export the Quantized int8 Model
Bash
python offline_train.py
Output:
Text
[TRAIN] Completed PyTorch training pass.
[EXPORT] Saved quantized int8 model to 'model_weights.npz' (321.06 KB in RAM)
Step 3: Run the Speed & Zero-Allocation Benchmark
Bash
python production_server.py --benchmark
Output:
Text
[BENCHMARK] 1,000 Transformer forward passes in 145.20 ms (0.1452 ms/req)
[SAMPLE OUTPUT] {"intent":"pricing","reply":"Nos forfaits commencent a 9$/mois.","kbd":["Acheter","Retour"]}
Step 4: Start the Live Production Server
Bash
python production_server.py
Output:
Text
[SERVER] Listening on http://127.0.0.1:8080 (50,000 User Table Active, < 10 MB RAM)
5. Testing the Live Server (curl)
Open a second terminal and test English, French, and Arabic/Tunisian queries:
Bash
# English Query
curl -X POST http://127.0.0.1:8080 -d "hello how much is the price"

# French Query
curl -X POST http://127.0.0.1:8080 -d "bonjour quel est le tarif svp"

# Arabic / Franco-Tunisian Query
curl -X POST http://127.0.0.1:8080 -d "مرحبا قداه السوم"
6. Optional PostgreSQL (asyncpg) Write-Behind Setup
The server runs standalone out-of-the-box without a database. To enable persistent write-behind batching to PostgreSQL:
Create the table in PostgreSQL:
SQL
CREATE TABLE IF NOT EXISTS user_events (
    uid INTEGER NOT NULL,
    lang SMALLINT NOT NULL,
    intent SMALLINT NOT NULL,
    ts BIGINT NOT NULL
);
Export DATABASE_URL before starting production_server.py:
Bash
export DATABASE_URL="postgresql://user:password@127.0.0.1:5432/mydb"
python production_server.py

import re

with open("offline_train.py", "r", encoding="utf-8") as f:
    code = f.read()

# Inject live timer + 1024 batch size + 15 epochs + chunked evaluation
pattern = re.compile(
    r"    n_total = x_np\.shape\[0\].*?logits_np = .*?\.astype\(np\.float32\)",
    re.DOTALL,
)

timed_block = """    import time
    n_total = x_np.shape[0]
    batch_size = 1024
    total_epochs = 15
    t_start = time.perf_counter()
    for epoch in range(total_epochs):
        perm = np.random.permutation(n_total).astype(np.int32)
        for start in range(0, n_total, batch_size):
            idx = perm[start : start + batch_size]
            opt.zero_grad()
            with torch.no_grad():
                params[0].data[0].zero_()
            logits_i = forward_torch(x_t[idx], valid_m[idx], valid_counts[idx])
            loss = -torch.sum(yi_oh[idx] * F.log_softmax(logits_i, dim=-1), dim=-1).mean()
            loss.backward()
            opt.step()
        elapsed = time.perf_counter() - t_start
        eta = (elapsed / (epoch + 1)) * (total_epochs - (epoch + 1))
        print(
            f"[EPOCH {epoch + 1:02d}/{total_epochs}] Loss: {loss.item():.4f} | "
            f"Elapsed: {elapsed:.1f}s | Finish in: {eta:.1f}s",
            flush=True,
        )

    with torch.no_grad():
        params[0].data[0].zero_()
        chunks = [
            forward_torch(x_t[s : s + 1024], valid_m[s : s + 1024], valid_counts[s : s + 1024])
            .cpu().numpy().astype(np.float32)
            for s in range(0, n_total, 1024)
        ]
        logits_np = np.concatenate(chunks, axis=0)"""

assert pattern.search(code), "Could not locate training block in offline_train.py"
code = pattern.sub(timed_block, code, count=1)

with open("offline_train.py", "w", encoding="utf-8") as f:
    f.write(code)
